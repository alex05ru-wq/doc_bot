# Telegram-бот: документы по шаблону

Бот задаёт пользователю вопросы по очереди и по ответам готовит документ
в двух форматах: **Word (.docx)** для правки и **PDF** для печати и отправки.

## Возможности
- Выбор документа кнопками (в примере: договор оказания услуг, заявление на отпуск, расписка)
- Пошаговые вопросы со счётчиком «Вопрос 2 из 6»
- Проверка ответов: числа, даты, телефоны
- Сводка перед созданием документа: можно проверить данные или заполнить заново
- Готовые файлы .docx и .pdf прямо в чат
- Копии документов владельцу (необязательно)
- Свои шаблоны делаются в обычном Word: вместо данных пишете `{{поле}}`

## Запуск
```
pip install -r requirements.txt
python make_templates.py      # создаёт примеры шаблонов (один раз)
```
Скопируйте `.env.example` в `.env` и впишите токен от @BotFather, затем:
```
python bot.py
```

## Как добавить свой документ
1. Сделайте файл в Word и положите его в папку `templates`.
   Вместо данных напишите поля: `{{client_name}}`, `{{price}}` и т.д.
   Поля `{{today}}` (сегодняшняя дата) и `{{doc_no}}` (номер) заполняются сами.
2. В `config.py` добавьте документ в `TEMPLATES`: название, путь к файлу и вопросы к каждому полю.

## Технологии
Python, pyTelegramBotAPI, python-docx, ReportLab
